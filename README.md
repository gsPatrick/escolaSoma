# Escola SOMA — novo site institucional

Novo site da Escola SOMA (Sorriso Mágico) — Soma Vila e Soma Garden, Abrantes, Camaçari-BA.

- `/` — página inicial
- `/apresentacao` — apresentação da proposta (pesquisa, identidade visual, conceito e próximos passos)
- demais links — página "em validação" até cada página interna ser aprovada

## Rodar localmente

```bash
npm install
npm run dev   # http://localhost:3100
```

## Stack

Next.js 14 (App Router) · JavaScript · CSS Modules · Atomic Design
(`components/atoms`, `molecules`, `organisms`).

A pesquisa de identidade e conteúdo, com fontes, está em [`reference/BRAND.md`](reference/BRAND.md).
